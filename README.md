\# CampusTrack — Campus Placement Management System



CampusTrack is a MERN stack web application designed to help manage campus placement activities in one centralized platform.



\## Project Objectives



\- Organize student placement information.

\- Manage company and recruitment details.

\- Track placement drives and student applications.

\- Perform CRUD operations on placement records.

\- Provide a foundation for a user-friendly placement management dashboard.



\## Technology Stack



\- \*\*MongoDB\*\* — Database

\- \*\*Express.js\*\* — Backend framework

\- \*\*React.js\*\* — Frontend library

\- \*\*Node.js\*\* — JavaScript runtime

\- \*\*Mongoose\*\* — MongoDB object modeling

\- \*\*Git and GitHub\*\* — Version control

\## Installation



Clone the repository:



```bash

git clone https://github.com/sunilsonawane29/CampusTrack.git

cd CampusTrack

```



Install backend dependencies:



```bash

cd backend

npm install

```



\## Environment Configuration



Create a `.env` file inside the `backend` folder:



```env

PORT=5000

MONGODB\_URI=your\_mongodb\_connection\_string

```



Replace the placeholder with your MongoDB connection string. Keep your actual `.env` file private and never commit database credentials to GitHub.



\## Run the Backend



From the `backend` folder, execute:



```bash

node server.js

```



The application uses port 5000 by default.



Ensure MongoDB authentication and connectivity are configured correctly.
